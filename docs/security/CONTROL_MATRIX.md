# Security Control Matrix

## Status rules

`Enforced` means code and a regression test exist. `Partial` means a useful
control exists with explicit residual risk. `Planned` names the sprint that must
implement it. Standards mappings are compatibility references and should be
revalidated when OWASP GenAI, NIST AI RMF, or MITRE ATLAS versions change.

## Maintenance contract

Every new major threat requires a matrix row, code owner, test owner, residual
risk, and standards mapping. A control cannot be marked `Enforced` from design
intent or a passing happy-path test alone. The relevant adversarial or invariant
test must fail when the control is removed.
